How playback works

AUTHORIZED SOURCE → SPITz-X API → FFmpeg → MP4 → /media/:videoId → native HTML5 player Playback URL = API/media/VIDEO_ID Download URL = API/media/VIDEO_ID/download
SPITz-X does not extract hidden YouTube stream URLs or bypass YouTube access controls. The playback URL is for media SPITz-X is authorized to host.
