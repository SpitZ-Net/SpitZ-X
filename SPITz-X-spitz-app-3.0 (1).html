2. Add an Authorized Copy

Use this only for a video your Tech Group owns or has permission to distribute. Paste the matching watch link, choose the authorized source file, and SPITz-X will convert it to MP4 and register it in the library.

No file selected

The current Render setup stores the library on the server filesystem. Render Free storage is temporary; use persistent/object storage for a permanent school-wide library.

How it works

WATCH LINK → video ID → SPITz-X authorized library → native HTML5 player

AUTHORIZED SOURCE → FFmpeg → MP4 → library → Watch / Download

SPITz-X does not attempt to bypass YouTube access controls or turn an arbitrary YouTube watch page into a downloadable stream.
