Backend Connection

GitHub Pages cannot perform server-side media extraction or video conversion. SPITz-X therefore connects to a backend that you control.

Only process media that you own or have permission to process.

Expected API

Your backend can expose endpoints such as:

POST /analyze { "url": "AUTHORIZED_VIDEO_URL" } POST /playback { "url": "AUTHORIZED_VIDEO_URL" } POST /convert { "url": "AUTHORIZED_VIDEO_URL", "format": "mp4" }

The frontend does not pretend these endpoints exist until you configure your own backend.

GitHub Pages

GitHub Pages is the easiest way to host the SPITz-X frontend.

  1. Create a GitHub repository.
  2. Upload the SPITz-X files.
  3. Open repository Settings.
  4. Open Pages.
  5. Select your branch.
  6. Save the deployment.

Your HTML, CSS and JavaScript can then be served as a static website.

Google Apps Script

Google Apps Script can be used when your deployment needs server-side functionality.

function doGet() { return ContentService .createTextOutput("SPITz-X API Online"); }

Deploy the Apps Script project as a web application, then place its URL into your SPITz-X API settings.

Custom SPITz-X Deployment

A custom deployment can use the same interface while changing the content, games, APIs and documentation.

my-spitz-site/ │ ├── index.html ├── spitz-app.html │ ├── css/ ├── js/ ├── Games/ └── api/

Keep the application modular so individual sections can be replaced without rebuilding the entire site.

Components

SPITz-X uses reusable interface patterns:

  • Panels
  • Navigation buttons
  • Status indicators
  • Game cards
  • Media processors
  • Documentation cards

Copy an existing component's HTML and modify its content rather than rebuilding the styling from scratch.
